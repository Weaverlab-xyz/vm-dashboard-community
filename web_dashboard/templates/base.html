{# `sticky` only while the row is folded. On a phone the bar is the only navigation affordance there is, and a dashboard runs 4+ screens: unpinned, reaching the menu means scrolling back to the top of the page first. It costs 64px of a ~850px viewport, which is the trade the pin is worth making and the wide row is not -- so the wide row keeps `relative` and every desktop pixel it had. z-30 is the floor that clears scrolling page content and stays UNDER the z-40 modal overlays, which should cover the bar.
