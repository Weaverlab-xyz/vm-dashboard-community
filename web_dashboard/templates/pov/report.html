{# The close-out report for one POV: what was covered, what was skipped, what was said, and who signed it off. Printed to PDF from the browser ("Print / Save as PDF"). Standalone, like /pov/access, and for a similar reason: it is a document, not a page of the dashboard, so it carries no nav and its own styles. The styles are INLINE rather than Tailwind on purpose -- tailwind.css is a committed build, and a print layout is the last place a class with no rule should go unnoticed. Three rules, each of which is a test (tests/test_pov_signoff.py): * no input of any kind. The customer's name and the opportunity are literal placeholders the SE replaces in the PDF or the document they paste it into, because this database is not approved to hold either -- see PovEnvironment; * no email address: every name here is a dashboard username; * everything a person typed is rendered with x-text. app.js is not loaded: this page needs a token and one fetch, the same reasoning as pov/access.html. #}
