"All environments on the platform" — a live read, including ones the dashboard never created. Read-only, because it does not own them. Collapsing the two would mean either offering a Destroy button for someone else's hand-built environment, or hiding it. Neither is right. The Broker column is the third thing on this page, and the one worth reading twice: "none" and "offline" are different failures with different fixes, so they are never collapsed into one "not working" badge. The BeyondTrust tenants section is the third inventory, and the one that decides WHOSE appliance a POV is wired into. It is deliberately on this page rather than in Settings: Settings holds the singletons a demo instance uses, and a second place to configure a tenant there is exactly the ambiguity install_profile removed. The Gateway column is where a POV becomes reachable: it is the BeyondTrust Gateway running INSIDE the environment, on the broker VM, registered into that POV's own PRA tenant. Its status is deliberately behind a button — it is a live read against a customer's appliance, and one per row would make this page as slow as the slowest customer's network. The Resource Broker column is the Windows half. Its installer comes from the customer's own Password Safe tenant, so the dashboard cannot fetch it — the customer uploads it on the Config Management page and names it here. Note there is no login field: that comes from the lab platform's own stored credentials, read per run. The Wired column is the per-VM PAM half: one PRA jump item per VM routed through THIS POV's own Gateway (the tenant's appliance-wide default has no route into the environment), and one Password Safe managed system reached THROUGH the Resource Broker. The three are independent — a POV with no Password Safe or Entitle tenant still wires into PRA. Entitle additionally needs an agent running inside the POV, which this dashboard does NOT install, and an SSH key from the template. The Share column is the only thing on this page a CUSTOMER opens. The URL is shown with a copy button rather than as a link on purpose: an accidental middle-click from here is an SE opening a session as the customer. The Expires column is the auto-delete timer. It warns on a ladder rather than once, because a POV outlives whoever set it up. #} {% block content %}
