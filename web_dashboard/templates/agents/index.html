Remote Agents

Containerised agents that run inside a private network and poll out to this dashboard for work — so on-premises Kubernetes clusters and databases can be discovered without opening a single inbound firewall rule. Each agent authenticates with an Ed25519 key it generates itself; no reusable credential ever crosses the wire.
