Deployed agents

Agents the dashboard builds for you in AWS, Azure or Google Cloud, to run Config Management on the VMs in that network. A host has no public address and no inbound rule. It can stay up, go away at a set time, or come up just before each occurrence of a change window and go away after it. How deployed agents work.
