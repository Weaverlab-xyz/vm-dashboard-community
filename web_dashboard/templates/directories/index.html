Directories

Active Directory domains that Windows servers on AWS and GCP can join at deploy. Build AWS Managed Microsoft AD or GCP Managed AD, or discover one that already exists (including AWS AD Connector and Simple AD) and register it. Directories bill around the clock and have no auto-delete timer. Register on-prem records an on-premises AD or LDAP directory reached through a remote agent, so Config Management playbooks can change it; Import from Password Safe does the same for directories Password Safe already manages. Register identity provider adds an Entra ID tenant, Okta org or PingOne environment: browse its users and groups, and, once you turn writes on for it, change group membership.

Register an on-premises directory

Reached through a remote agent (2.8 or later). Its policy.yaml must allow the host on the LDAP port, and on 5986 for WinRM playbooks. The bind account is a Password Safe managed account, checked out for each run.

Enter the org name (acme or acme.okta.com): the host (acme.ldap.okta.com), LDAPS on 636 and base DN are filled in. The Okta LDAP Interface is search-only, so only ldap-search.yml runs against it; change users and groups through the Okta identity provider instead.

Connect to a GCP network

Builds one small VyOS VM on GCP (e2-small about $12/month, plus a static IP about $3.65/month) and a WireGuard tunnel to your on-prem VyOS router. Your router dials out to it, so it needs no static IP and no inbound port. The VPC routes your on-prem subnets to the peer, and the peer answers DNS for the domain, so a DNS link can point at it. It is a single VM: use it for labs and POVs, not for a domain production servers depend on.

On your on-prem VyOS 1.4 router, in configure mode, run generate pki wireguard key-pair install interface wg0 and paste the public key it prints below. Its private key stays on the router. After the build, On-prem commands gives you the rest to paste.

The image is the vyos-cell bake (VyOS 1.4) with the GCP Ansible key's public half as VYOS_RUNNER_PUBKEY: the dashboard's Cloud Run runner configures the peer with it. The peer's WireGuard private key is generated here and kept in GCP Secret Manager only.

On-prem VyOS commands

Paste these into configure mode on your on-prem router. They hold no secret. Allow the tunnel and the VPC ranges through your firewall on the AD ports, then use Check link.
