Build a certificate authority

A CAS pool, a self-signed root CA, and the enrollment service account the plugin authenticates as. Destroying it removes all three in one pass — the module sets the three flags CAS otherwise uses to refuse deletion.

The pool, its CAs and any certificate template are all location-scoped and must agree.

Add a certificate identity

One managed account per identity. The account name becomes the subject CN by default, and the whole profile below becomes the managed system's Network Address.

A pipeline identity is not a host, so usually leave this empty — and note that under eku=Auto a DNS SAN drags serverAuth into the EKU set.

CA chain

Hand this to the mTLS endpoint playbook as ca_chain_pem. It is the ssl_client_certificate nginx verifies presented certificates against.
